## WHAT MOVEYOU IS

MoveYou is a fast-growing European IT company that develops a white-label, multi-tenant SaaS mobility platform designed for businesses in the energy, mobility, and fueling domains.

Core Mission: Enable traditional petrol station operators and mobility providers to evolve into future-proof, full-service mobility hubs by automating operations, diversifying into electric mobility, and delivering flexible, integrated services.

Platform Type: API-first, microservices-based, white-label SaaS platform

Geographic Focus: Europe-wide coverage and operations

## PLATFORM ARCHITECTURE

MoveYou consists of four main integrated components:

### 1. Petrol Manager System (PHP)
Platform that manages all aspects of petrol station operations including forecourt management, product catalogs, pricing, and station-level controls.

### 2. Insights Platform (Core API Backend)
- API-first, microservices-based backend layer built with Laravel
- GraphQL API for all integrations
- Connects with external systems (ERP, finance, operational tools)
- Used internally by tenants' customer support and business operations teams
- Powers all other platform modules

### 3. White-Label Self-Service Portal
- Customizable portal for tenants' end customers
- Manage invoices, vehicles, orders, and employees
- Built with Angular Formly frontend
- Fully brandable to tenant specifications

### 4. White-Label Mobile Apps (iOS/Android)
- Used by both individual (B2C) and employee (B2B) users
- Features: transaction management, charging/parking session control, invoice viewing, ride analytics
- Fully branded to tenant specifications
- Learn more: https://moveyou.com/white-label-mobility-apps/

## TERMINOLOGY & DISAMBIGUATION

Brand Name: "MoveYou" is written as one word with camelCase (capital M and Y). Never write "Move You", "MoveU", "move you", or "moveyou".

Charging Cards: Terms like "charging card", "charge card", "laadpas" (Dutch), and "ladekarte" (German) refer to physical or virtual payment cards for EV charging. MoveYou enables white-label issuance and management of these cards.

Forecourt: Refers to a fuel/energy retail site (petrol station) and its on-site operations, including fuel pumps, convenience stores, car wash, and increasingly, EV chargers.

e-MSP: e-Mobility Service Provider - companies that provide charging services to EV drivers, often across multiple charging networks.

CPO: Charge Point Operator - companies that own and operate EV charging infrastructure.

White-Label: Technology or services that can be rebranded and sold under a customer's own brand name. MoveYou's platform is fully white-labelable.

Multi-Tenant: Software architecture where a single instance serves multiple customers (tenants), each with isolated data and custom configurations.

CPMS: Charge Point Management System - software for managing EV charging infrastructure.

OCPP: Open Charge Point Protocol - standard communication protocol between charging stations and management systems.

MAS: Mobility Authorization Server - system for authorizing and authenticating mobility transactions.

TOMP-API: Transport Operator to Mobility Provider Application Programming Interface - standardized interface for mobility data exchange.
